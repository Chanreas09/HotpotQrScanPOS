# 🍲 Hotpot & Snacks Ordering System

A complete restaurant ordering system designed for hotpot and snacks restaurants. Customers can browse the menu, select items, and place orders directly to the kitchen via Telegram.

## ✨ Features

- 📱 **Mobile-friendly** ordering interface
- 🍜 **Full menu management** with categories
- 📋 **Real-time order summary** with quantity controls
- 🔧 **Admin mode** for menu management (Password: 1369)
- 📤 **Telegram integration** for sending orders to kitchen
- 📊 **Order history** tracking
- 🧾 **Printable receipts**

## 🚀 Live Demo

**[View Live Site](https://hotpot-qr-scan-pos.vercel.app/)**

## 🛠️ Tech Stack

- HTML5 + CSS3 + JavaScript (Vanilla)
- Firebase Realtime Database (optional)
- Telegram Bot API
- Vercel (Serverless Functions)
